## 0. 프로젝트 개요

사용자가 할 일을 직관적으로 관리할 수 있도록 지원하는 대시보드 웹 사이트 입니다.
주요 기능으로는 할 일, 진행 중, 완료 상태에 따라 태스크를 분류하는 시스템과 라이트 및 다크모드를 부드럽게 지원하는 테마 전환 기능이 들어 있습니다.

사용자가 직접 수정 가능한 닉네임 입력 영역과 실시간 날짜 표시 기능을 제공하며, 우선순위 설정, 카드 마우스 호버 시 나타나는 애니메이션 삭제 버튼, 그리고 모달창을 활용한 기록할 수 있는 웹사이트 입니다.

### 3-2. 파일 별 담당 구조
- reset. css: 브라우저마다 다르게 설정되어 있는 기본 여백과 스타일을 깔끔하게 초기화하여 모든 브라우저에서 동일한 기준선으로 웹사이트를 시작할 수 있도록 담당
- base.css: 전체 기본 레이아웃 스타일을 담당
- component.css: 웹사이트를 구성하는 개별 시각적 요소들의 세부 디자인과 애니메이션을 담당
- theme.css : 상태에 따른 배경색, 카드 색상, 텍스트 및 테두리 색상의 변수 값 변경과 스타일 전환을 담당
- responsive.css : 태블릿이나 모바일 기기의 화면 크기에 맞춰 배치가 유연하게 변하도록 반응형 디자인을 담당
- generation.js : 닉네임 실시간 수정 및 글자 수 제한, 실시간 날짜 업데이트, 칸반 보드 내 카드 동적 생성 및 삭제 처리, 모달창 제어 등의 자바스크립트 인터랙션 기능을 담당

### 6-2. 디자인 불균형 문제
대시보드의 핵심인 3가지 상태 영역(할 일, 진행 중, 완료)에 등록된 카드 개수가 서로 다를 때, 특정 칸만 세로로 과도하게 길어지거나 그리드 정렬이 깨져 전체적인 화면 균형이 무너지는 현상입니다

board-column와 내부 column-cards-area에 강제적인 최소 높이가 과도하게 설정되어 있고, 카드 개수가 적을 때 남은 공간을 유연하게 채우지 못해 발생합니다.

CSS에서 불필요한 min-height를 축소하고, 내부 카드 영역에 flex: 1 및 컨테이너에 height: 100%를 부여하여 모든 칸이 상단 기준(align-items: start)으로 균일한 비율을 유지하도록 레이아웃 규칙을 재조정합니다

### 6-3. js 영역 트러블 슈팅

1.새로운 기능 추가 후 기존 기능 전체가 동작하지 않는 문제
문제 상황
검색어 상태 표시, 기간 필터 등 새로운 JavaScript 코드를 추가한 뒤 기존에 동작하던 정렬, 드롭다운, 우선순위 필터까지 모두 실행되지 않는 문제가 자주 발생했습니다.


필터와 정렬 기능을 추가한 뒤 기존 기능이 동작하지 않는 문제
문제 상황
검색, 기간, 우선순위 필터 기능을 추가한 뒤 오름차순·내림차순 정렬이나 일부 필터가 Todo 카드에 적용되지 않았습니다.

드롭다운을 클릭해도 열리지 않거나 선택값이 적용되지 않는 문제
문제 상황
기간 또는 우선순위 드롭다운 버튼을 눌러도 메뉴가 열리지 않거나, 항목을 선택해도 Todo 목록에 반영되지 않았습니다.

필터 상태 표시와 실제 적용된 조건이 서로 다른 문제
문제 상황
Todo 목록에는 높음 우선순위가 적용되어 있지만, 하단 상태 표시에는 전체 우선순위가 표시되는 등 화면의 상태 정보가 일치하지 않았습니다.(전체기간,정렬:오름차순,내림차순 포함)

전체 데이터 삭제 버튼을 눌러도 카드와 모달이 그대로 남는 문제
문제 상황
전체 데이터 삭제 모달에서 삭제 버튼을 눌러도 Todo 카드가 제거되지 않고 모달도 닫히지 않았습니다.

깃허브 업로드 시 이전 파일 덮어쓰기 현상-> 원인 : branch 새로 안 따고 dev에 바로 push -> 해결 : push 한 내역 취소하고 branch 새로 따서 PR

개별 삭제랑 전체 초기화 버튼 겹침 -> 원인 : 전체 초기화 버튼과 개별 삭제 버튼을 하나의 모달과 확인 버튼을 공유해서 사용 
             앞에서 실행했던 이벤트가 누적되면서 같이 실행되어버림

  -> 해결 : X버튼 누를 때 그 카드의 ID를 기억해서 확인 눌렀을 때 개별인지 전체인지 컴퓨터가 구분하는 방식으로 해결 

삭제하려고 X버튼 눌렀는데 수정 모달 창이 뜸 -> 원인 : X버튼까지 수정 모달을 눌렀다고 인식-> 해결 : 만약 X버튼 누른거라면 당장 함수 종료하는 방식으로 해결

새로고침 시 기존에 작업물들 전부 사라지는 현상-> 원인 : 로컬스토리지에 반영하는 코드 누락-> 해결 : renderTodos() 이전에 로컬스토리지 코드를 추가해서 데이터가 로컬스토리지에 동기화되도록 개선

사용자 입력 이름 칸에 Enter 클릭 시 줄바꿈 또는 완료가 안 되는 현상-> 원인 : 엔터를 눌렀을 때 발생하는 이벤트보다 브라우저의 기본 동작이 우선 실행 됨-> 해결 : event.preventDefault() 브라우저의 기본 줄 바꿈 기능 억제하는 코드 적용

카드 추가했는데 뱃지에 추가 된 카드 개수가 갱신이 되지 않음-> 원인 : 개수 판 새로고침 해주는 코드 누락-> 해결 : updateAllCount() 를 추가해서 실행 직후 배지 개수 갱신되도록 해결
