## 0. 프로젝트 개요

사용자가 할 일을 직관적으로 관리할 수 있도록 지원하는 대시보드 웹 사이트 입니다.
주요 기능으로는 할 일, 진행 중, 완료 상태에 따라 태스크를 분류하는 시스템과 라이트 및 다크모드를 부드럽게 지원하는 테마 전환 기능이 들어 있습니다.

사용자가 직접 수정 가능한 닉네임 입력 영역과 실시간 날짜 표시 기능을 제공하며, 우선순위 설정, 카드 마우스 호버 시 나타나는 애니메이션 삭제 버튼, 그리고 모달창을 활용한 기록할 수 있는 웹사이트 입니다.

## 3. 프로젝트 구조 및 아키텍처

### 3-1. 디렉터리 구조
```
flowdash/
├─ assets
├─ README.md
├─ index.html
└─ cssfolder/
   ├── reset.css
   ├── variables.css
   ├── base.css
   ├── layout.css
   ├── components.css
   ├── theme.css
   └── responsive.css
└─ js/
   ├─ main.js
   ├─ state.js
   ├─ storage.js
   ├─ utils/
   │  └─ date.js
   └─ ui/
      ├─ board.js
      ├─ card.js
      ├─ header.js
      └─ stats.js
```

### 3-2. 파일 별 담당 구조
- reset. css: 브라우저마다 다르게 설정되어 있는 기본 여백과 스타일을 깔끔하게 초기화하여 모든 브라우저에서 동일한 기준선으로 웹사이트를 시작할 수 있도록 담당
- base.css: 전체 기본 레이아웃 스타일을 담당
- component.css: 웹사이트를 구성하는 개별 시각적 요소들의 세부 디자인과 애니메이션을 담당
- theme.css : 상태에 따른 배경색, 카드 색상, 텍스트 및 테두리 색상의 변수 값 변경과 스타일 전환을 담당
- responsive.css : 태블릿이나 모바일 기기의 화면 크기에 맞춰 배치가 유연하게 변하도록 반응형 디자인을 담당
- generation.js : 닉네임 실시간 수정 및 글자 수 제한, 실시간 날짜 업데이트, 칸반 보드 내 카드 동적 생성 및 삭제 처리, 모달창 제어 등의 자바스크립트 인터랙션 기능을 담당

## 4. 핵심 설계 결정 사항 (Design Decisions)

- status 기반 보드 분리 → 상태 필터 제거
- 모든 날짜 데이터는 timestamp(number)로 통일
- 기간 필터 → 정렬 → 검색 순서의 고정 파이프라인 적용
- 통계는 기간 필터와 무관하게 전체 Todo 기준으로 계산
